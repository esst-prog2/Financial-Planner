04/05
What I learned

The lost localStorage

I did my corrections — came back a week later, and they were just gone: everything lives only in this browser, with nothing backing it up anywhere else.

Before Gone, no way back
Now Save to file → Restore from file

Now a repair step runs first automatically — and if that still fails, I can restore from a file I saved myself. Nothing lives in only one place anymore.
